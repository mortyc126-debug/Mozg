# Э3: картину мира строит мозжечок, нерв только доставляет. Предрегистрация, до кода

Предложение автора после Э2: «снять задачу с нерва и дать её мозжечку». В Э2 мозжечок советовал рулю (руль видел и нерв,
и прогноз) -- и мешал: два почти одинаковых входа. И предсказывать ему было нечего сверх шума чтения нерва (0.1).

Здесь шум -- **работа мозжечка**. Нерв доставляет сырое чтение; мозжечок сводит своё ожидание (что будет после моей
команды) с тем, что сказал нерв, -- оценка состояния, как фильтр Калмана. Мотор видит **только** эту оценку.

## 1. Мозжечок-оценщик (`CER = 3` с копией команды, `CER = 4` без неё)

- Прямая модель -- как в Э2 (подгонка по записи мотора раз в 500 кругов, копия команды `u` -- при `CER = 3`).
- **Оценка каждый круг:** ожидание `x̃(t) = x̄(t−1) + Δ̂(x̄(t−1), u(t−1))`; оценка `x̄(t) = x̃(t) + K_k·(x(t) − x̃(t))`.
- **Доверие нерву `K_k`** -- для каждого нерва своё, из {0.1, 0.2, 0.3, 0.5, 0.7, 1}: то, при котором ожидание по записи
  лучше всего угадывает следующее чтение нерва (так выбирается установившийся коэффициент Калмана). `K = 1` -- оценка равна
  нерву: если мозжечок не помогает, мотор видит нерв как прежде.
- **Мотор ожиданий видит только оценку `x̄`:** руль цели, сигнатура (цель руля) и команда -- по `x̄`. Прежний мотор (пока
  целей нет) -- по нервам, как раньше.

Остальное -- М3в в копии (`KEXP=3 MEXP=2`), без экономики.

## 2. Условия -- мир М3, 24 мира (сиды 1-24, 40000 кругов)

| условие | что | файл |
|---|---|---|
| **Б** | М3в, мотор видит нервы -- из Э1 | `../e1/e1_B.json` |
| **МК** | оценка мозжечка с копией команды (`CER=3`) | `e3_K.json` |
| **МК0** | оценка без копии (`CER=4`) | `e3_N.json` |

## 3. Меры -- вторая половина жизни, парно по мирам, двусторонний Уилкоксон, `p < 0.01`

0. **Мозжечок видит лучше нерва:** средний квадрат ошибки оценки `x̄` против **настоящего** запаха (мир знает его без шума),
   делённый на то же у сырого нерва. У МК меньше 1 (Уилкоксон против 1) и меньше, чем у МК0.
1. **Тело ест больше:** еда + вода у МК больше, чем у Б.
2. **Дело в копии команды:** еда + вода у МК больше, чем у МК0.

Дополнительно: смерти, по нужде, обесценивание; выбранные `K` по нервам.

## 4. Предсказания

- Мера 0 -- **да**: запах меняется плавно, а шум чтения -- каждый круг заново; усреднение по времени через прямую модель
  снимает большую часть шума (ожидаю отношение 0.3-0.6). Копия команды помогает: поворот сдвигает запахи слева и справа,
  и без копии ожидание отстаёт.
- Мера 1 -- **да**: руль по чистым запахам точнее.
- Мера 2 -- **слабо**.
