# Предрегистрация шага 63: новая статистика строки 0

Написано до кода и до прогонов. Механизма нет: статистика и её проверка.

## 1. Откуда

Шаг 62: `H(T) = (нуль − ткань) / (нуль − оптимум)` по каждому сиду при `T = 30` не
повторяется. Больше циклов не помогают: на отдельной партии тишин знаменатель
(знание, сохранённое оптимальным наблюдателем) почти ноль, и отношение взрывается
(286, −2.7). Нужна статистика без деления на шумную малую величину в каждом сиде.

## 2. Сбор данных -- как в шаге 62 (новый протокол)

100 циклов на каждую длину тишины (100 кругов жизни -- `T` кругов тишины -- первый круг
жизни). По сиду и длине копятся суммы: `ткань = Σ(прогноз − L)²` по частям медленного
канала, `нуль = ΣL²` (по тем же частям), `оптимум = Σ(прогноз Калмана − L)²` (по тем же
частям). Отдельно -- по первым 50 и вторым 50 циклам.

## 3. Две статистики

- **А -- отношение сумм по всем сидам:**
  `H_А(T) = Σ_сиды(нуль − ткань) / Σ_сиды(нуль − оптимум)`. Одно число на прогон. Малый
  знаменатель отдельного сида тонет в сумме.
- **Б -- аналитический эталон:** по сиду `H_Б(T) = (1 − ткань/нуль) / K(T)`, где `K(T)` --
  доля дисперсии `L`, которую сохраняет оптимальный наблюдатель, посчитанная заранее
  (шаг 42): `K(10) = 0.534`, `K(30) = 0.238`. Знаменатель -- постоянная. По сидам --
  медиана.

Обе при идеальном измерении дают то же, что прежняя `H`: долю пронесённого знания
относительно оптимума.

## 4. Проверка (сиды 3701-3712, действующий зародыш, 60000 кругов прогрева)

- **А принимается**, если стандартное отклонение `H_А(30)` по бутстрепу сидов (2000
  повторов, жребий закреплён) не больше **0.10** **и** `H_А(30)` по первым и вторым 50
  циклам расходятся не больше чем на **0.15**.
- **Б принимается**, если повторяемость `H_Б(30)` (медиана по сидам модуля разности
  половин, делённая на √2) не больше **0.15**.
- **Та же ли это мера:** при `T = 10`, где прежняя мера здорова (шаг 62: повторяемость
  0.04), принятая статистика отличается от медианы прежней `H(10)` на этих данных не
  больше чем на **0.1**.

**Выбор:** если проходит А -- берётся А. Иначе, если проходит Б, -- Б. Иначе строка 0
остаётся на старой мере с оговоркой.

Принятая статистика заменяет прежнюю в батарее для строки 0 с порогом 0.5 при `T = 10`
и `T = 30`. На данных этой проверки (действующий зародыш) по ней сразу считается статус
строки 0.

## 5. Предсказания

1. А проходит: бутстреп около 0.05.
2. Б тоже проходит, повторяемость около 0.1.
3. При `T = 10` обе совпадают с прежней в пределах 0.05.
4. Строка 0 у действующего зародыша по новой статистике -- ЕСТЬ, `H(30)` около 0.5-0.6,
   то есть на грани.
