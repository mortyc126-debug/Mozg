# Результат шага 66: пауза записывает свои входы -- принято; линия задержки -- снова нет

Предрегистрация -- `PRE66_PAUSEX.md`, закоммичена до кода. `PAUSEX = 1`: пауза записывает
входы своего прогноза, как круг жизни. При `PAUSEX = 0` движок побитово прежний (`id66.js`, в
том числе с `DLINE = 6`; движок до шага -- `history/neuron2_run6.js`).

## Катастрофа снята

Путь сида 3809 (`diag3809.js`) при `PAUSEX = 1`: сумма ошибки ткани при `T = 30` -- **584** при
нуле 704 (было **8.2·10⁶** при нуле 839). Вес частей медленного канала на себя держится 0.89-0.93
во всех паузах. Условие «не больше двух сумм нуля» -- выполнено.

## Приёмка

- **`PAUSEX` -- принят:** катастрофа снята, в П против Б ни одна строка не потеряла статуса.
  Строка 0 при `T = 30` выше и ровнее (0.754 ± 0.056 против 0.660 ± 0.085). Строки, меряемые до
  пауз, совпадают с Б до знака: пауза есть только в мере строки 0. `embryo.env` дополнен
  `PAUSEX=1`.
- **Линия задержки -- не принята:** в ПЛ против П потеряна «3 длинная тишина» (медленный канал
  0.852 при пороге 0.9, в П -- 0.914).

## Что это значит

- Провал строки 0 в шагах 62-64 был **изъяном паузы в замере**, а не свойством ткани. С
  поправкой строка 0 держится уверенно: нижняя граница `H(30)` на двух отклонениях -- около 0.64.
- Вред линии задержки строке 0 в шаге 64 был **отчасти той же порчей при пробуждении**: с
  поправкой строка 0 с линиями держится. Но **остаётся вред медленному каналу в длинной
  тишине** (0.85 против 0.91). Линии по-прежнему заметно усиливают перенос глубокого прошлого
  (строка 4: 12 из 12 сидов, 2.87 бита против 2.21; путь В 12 из 12).
