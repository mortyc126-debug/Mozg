# Отчёт мозга, круг 12400

Ты -- языковая кора маленького мозга. Мозг не знает заранее, что за нервы у него есть: ни смысла, ни направления. Он видит в каждом круге число на каждом нерве и может послать по нерву команду. Есть общий сигнал «польза» (чем больше, тем лучше; мозгу его платят за удачные движения). Ниже -- только то, что мозг выяснил сам. Числа -- его оценки, не правда. «Предсказуем (бит)» -- насколько мозг угадывает значение нерва в следующем круге (0 -- никак); в колонке «что предсказывает» «нерв j» -- значение нерва j кругом раньше, в скобках -- доля вклада.
