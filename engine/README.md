# Цифровой биологический движок

Ядро без визуализации. Запускается на Node.js, зависимостей нет.

## Принцип

В коде нет сущностей выше агента. Нет ни «ткани», ни «оси», ни «рецептора», ни «нейрона».
Есть среда с полями, агенты, геном как набор правил и физика. Всё остальное —
следствие, которое можно только измерить снаружи.

Геном тоже не содержит ролей. Ген — это правило

```
target = sigmoid(act · in) * (1 - sigmoid(rep · in))
```

и вектор эффекторов: во что превращается его экспрессия.

| эффектор | смысл |
|---|---|
| `sec[f]` | выделение вещества в поле `f` |
| `sens[f]` | перевод поля `f` в возбуждение |
| `adh` | вклад в липкость |
| `mot` | вклад в подвижность |
| `div` | вклад в стоимость деления |
| `link` | склонность образовывать связь |
| `reach` | прибавка к дальности связи |
| `pol` | использование локальной асимметрии окружения |

Роль вроде «чувствительная клетка» — это не сущность, а ненулевое число в `sens`.
Поэтому мутация может создать или уничтожить роль, не меняя ни строки кода.

## Что есть в ядре

Среда: шесть полей. Три выделяемые агентами, одно с ресурсом, одно для внешнего
воздействия, одно неподвижное — градиент среды со случайным направлением.
Диффузия и распад считаются явно.

Агент: энергия, обмен веществ с расходом на экспрессию, деление при избытке
энергии и свободном месте, гибель при исчерпании, объём, дифференциальная адгезия,
подвижность.

Связи: растут между агентами, у которых достаточна склонность `link`, в пределах
дальности, зависящей от `reach`. Отмирают, если не используются.

Возбуждение: накопление входа с утечкой, порог, рефрактерный период, утомление.
Вес связи растёт при совпадении активности и при подпороговом сдвиге,
слабеет без использования, суммарный вес входов клетки ограничен.

### Механизмы, добавленные позже; по умолчанию выключены

Каждый вводился под невыполненную функцию, а не потому, что он есть у биологии.
У каждого проверено ТОЖДЕСТВО ПРИ НУЛЕ: с выключенным параметром поведение
движка побитово прежнее, и ни одного случайного числа лишнего не тратится —
иначе поток RNG сдвинулся бы и сравнение перестало быть сравнением одного и
того же прогона.

| параметр | что вводит | этап |
|---|---|---|
| `polarity` | локальная асимметрия окружения действует на агента | 4 |
| `twoPoint`, `bodyLength`, `bodyStiff`, `bodyRadius` | у агента появляется ФОРМА: две связанные точки, а с ней возможность деформации | 6 |
| `align`, `alignSelf`, `alignRate` | согласование ориентаций между соседями | 7–8 |
| `junction`, `junctionBreak`, `junctionMax` | закреплённый контакт: память о том, кто чьим соседом был | 11 |
| `junctionAdhesion` | сцепление ТОЛЬКО через закреплённый контакт | 11 |
| `gradAlign`, `gradField`, `gradHalf` | чтение градиента среды: ориентация тянется к направлению возрастания поля | 13 |

**Про `junctionAdhesion` стоит сказать отдельно: это замена механизма, а не
добавка к нему, и она меняет КАТЕГОРИЮ МАТЕРИАЛА.** Обычное сцепление
притягивает любого оказавшегося рядом агента, поэтому под нагрузкой соседи
просто меняются местами: ткань ведёт себя как капля, локальное сокращение
рассасывается и до формы не доходит. Закреплённые контакты, добавленные ПОВЕРХ
сцепления, дают лишь +6 п.п. сохранности соседей — два механизма борются друг с
другом. Если же притяжение оставить только между закреплёнными партнёрами
(отталкивание остаётся всеобщим), сохранность за 400 шагов растёт с 65% до 90%,
и жёсткость начинает помогать монотонно. Ткань при этом не застывает: путь
агента за шаг прежний, а снос от начального положения вдвое меньше — это
подпись упругости, а не заморозки.

## Структура

```

src/genome.js     геном, мутации, случайный геном
src/world.js      среда, агенты, физика, регуляция, связи, возбуждение
```

## Запуск

```bash
node bin/run.js 5 1600          # один прогон: сид мира, число шагов
node test/parity.js             # проверки
node bin/sweep.js 100           # сто мутантов, результат в results/sweep.jsonl
node bin/report.js              # сводка
```

Эксперименты запускаются так же: `node experiment/<имя>.js`. Часть из них
печатает сводку в консоль, часть пишет `.jsonl` в `results/`.

### Эталон для проверки тождества — не удалять

`test/junction_identity.js` сверяет нынешнее ядро с НЕТРОНУТЫМ и требует путь
к нему аргументом. Нетронутое ядро — это `../digital-life-engine.tar.gz` в
корне репозитория: снимок движка ДО закреплённых контактов (этап 10,
`src/world.js` на 534 строки). Как копия рабочей директории он устарел и
устареть должен: его ценность именно в том, что он не меняется.

```bash
mkdir -p /tmp/orig && tar xzf ../digital-life-engine.tar.gz -C /tmp/orig
node test/junction_identity.js /tmp/orig/digital-life-engine
```

Проверено 2026-09-20: тождество при `junction = 0` подтверждено на всех
6 сверках (точечный и двухточечный агент, сиды 5/77/2024, 600 шагов, полное
состояние без допуска).

## Измерения

Ни одно измерение не знает функциональных имён. Считаются: число агентов,
устойчивые состояния экспрессии (агенты группируются по двоичному профилю),
форма каждой группы (вытянутость, доля внутри ткани, пустота центра),
связность сети, пространственная анизотропия экспрессии, кривизна границы,
отклик на внешнее воздействие и его изменение после повторов.

Меры формы, появившиеся вместе с вопросом об изгибе, стоят отдельного слова.
Габаритная ширина СМЕШИВАЕТ изгиб и разброс: у дуги она велика просто потому,
что дуга изогнута, и «большой прогиб при большой толщине» неинтерпретируем в
принципе. Поэтому изгиб читается ОТНОШЕНИЕМ прогиба к остатку подгонки
параболой: заметно больше единицы — дуга, около единицы и меньше — облако.

Интерпретация делается после эксперимента и отдельно от кода.

Ход разработки и карта причинности — в `DEVELOPMENT.md`.

## Чего пока нет

Третьего измерения и просвета. Отбора: мутации есть, приспособленности нет.
Движения организма как целого — обратной связи «возбуждение → усилие → смещение
в среде» пока не замкнуто.
