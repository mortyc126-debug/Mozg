# Мотор ожиданий, шаг М3д: цена по нерву нужды, выбор цели по цене. Предрегистрация, до кода

Откуда -- `ИТОГ_М.md`, М3г. Квадратичная цена по всем нервам переобучилась (21 признак на 25-50 событий); выбор
«цена × выигрыш руля» тянет к близкой дешёвой еде; «нет цели -- прямо» хуже прежнего мотора. Лучшее -- М3в.

## 1. Правка -- `MEXP = 4` (= `MEXP = 2`, руль по сигнатуре, и две правки)

1. **Нерв нужды вида** -- нерв, который в событиях вида **растёт** (знак «+» в прототипе набора скачков), самый частый,
   если он есть хотя бы в 30% событий; свои нервы мотора не в счёт. У «еды» ожидаю сытость, у «воды» -- напоённость. Нет
   такого нерва -- вид не цель.
2. **Цена по нерву нужды:** `w_e = c0 + c1 n + c2 n²`, `n` -- нерв нужды перед событием; подгонка (гребень) по последним
   300 событиям вида, раз в подгонку руля (500 кругов). Три признака -- без переобучения. Это гомеостатическое
   подкрепление: событие ценно тем, насколько низок сейчас нерв, который оно поднимает.
3. **Выбор цели -- по цене:** заметность `s_e = w_e(n сейчас)`. Цели -- только «к» (вид со скачком пользы вверх, цена
   больше 0) с рулём, у которого F ≥ 3. Удержание 1.2. Нет цели -- прежний мотор (как М3в).

`MEXP = 0-3` не меняются. Тождество -- `tools/check.js`.

## 2. Условия -- мир М3, 24 мира

| условие | что | файл |
|---|---|---|
| **Б** | прежний мотор -- из М3б | `m3b_B.json` |
| **МС** | М3в | `m3v_M.json` |
| **МД** | `KEXP=3 MEXP=4` | `m3d_M.json` |
| **П** | вшитое правило -- из М3 | `m3_P.json` |

## 3. Меры -- как М3 (против Б); дополнительно -- против М3в

0. Еда и вода -- разные виды, ≥ 20 из 24.
1. По нужде: медиана МД ≥ 0.65 и МД выше Б, `p < 0.01`.
2. Обесценивание: медиана МД ≤ 0.5 и МД ниже Б, `p < 0.01`.
3. Ест и пьёт: МД больше Б, `p < 0.01`.

Дополнительно печатается: МД против МС; нерв нужды по видам (какой найден); цена еды в сытых блоках (`diagdeval.js`).

## 4. Предсказания

- Нерв нужды: у «еды» -- сытость, у «воды» -- напоённость, в большинстве миров.
- Мера 1 -- **да или около** (≥ 0.6): цель выбирает нужда, как у вшитого правила.
- Мера 2 -- **ближе, но нет** (0.5-0.7): в сытом блоке цена еды ~0 и цель «еда» не выбирается, но еду по дороге к воде
  тело всё ещё ест.
- Мера 3 -- **да**; против М3в -- без значимой разницы.
