# Нейрон-5

Новое ядро с чистого листа: одна шина для всех органов, плата по вкладу, гиппокамп в ядре, тело и язык в одном мире.
План и принципы -- `PLAN.md`. Нейрон-4 (`../neuron4`, `../neuron4k`) -- мерка, против которой сдаются экзамены.

Запуск экзамена ступени 1 для одного мира: `node tools/exam1.js <сид> [РУЧКА=значение ...]`; все ручки -- `src/config.js`.

| ступень | что | итог |
|---|---|---|
| **1** | ядро, ствол (рефлексы), кора, гиппокамп: понимает слова о своей жизни | события 0.90–1.00, состояния 0.70–0.85, контроль 0.5; в 41 раз быстрее нейрона-4; мера «не хуже нейрона-4» не пройдена по слову «опасно» (в мире нейрона-5 у него ниже потолок) -- `results/s1/ИТОГ.md` |
| **2а** | ценность и базальные ганглии: сила рефлексов по пробам | польза выше, чем на рефлексах как есть (2.55 против 2.42, 19 из 24 миров); веса «к еде» и «к воде» выросли в полтора раза, «от хищника» упал; укусов больше; мера «понимание не теряется» не пройдена по слову «голодно» (тело сытее -- слово звучит вдвое реже) -- `results/s2a/ИТОГ.md` |
