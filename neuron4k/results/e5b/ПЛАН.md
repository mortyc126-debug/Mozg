# Э5б: учёба отдела выбора -- по пробам, а не по совпадениям. Предрегистрация, до кода

Откуда -- `../e5/ИТОГ.md`. Отдел выбора учил веса смеси предложений целей, и веса вышли шумом: у целей «к еде» треть весов
отрицательна, у цели «от» знаки как у монетки. Автор: чинить сам элемент учёбы.

## 1. Диагноз

Учёба Э5 -- регрессия прироста пользы с ценностью на `u · предложение`. Но команда `u` целиком задана обстановкой
(она и есть смесь предложений), своей изменчивости у неё нет. Поэтому учёба видит **совпадения**, а не **причины**:
- рядом с хищником предложение «от» сильное -- и рядом же кусают: «слушался "от" -- укусили» → вес «от» вниз;
- рядом с едой предложение «к» сильное -- и еда приходит, потому что тело уже рядом, а не потому что послушалось.

Ценность `V(x)` линейна по нервам и вычесть «так сложилось» не может. Короткий горизонт (один круг) -- вторая беда,
но не главная: длинный горизонт на совпадениях дал бы те же совпадения.

## 2. Правка -- учёба по пробам (`MBLEND = 2`), как изменчивость в базальных ганглиях

В природе в движение подмешиваются малые случайные отклонения (у певчих птиц -- узел LMAN базальных ганглиев), а
дофамин отвечает: стало лучше или хуже. Отклонение случайно, обстановка с ним не связана -- связь причинная.

- **Смесь:** `u = Σ_e (α_e + ξ_e + (γ_e + ζ_e) · обстановка_e) · предложение_e`, в единицах руля (вес 1 -- «слушаться
  цель целиком», как при выборе одной цели). Обстановка и предложения -- как в Э5. Сила по разбросу `G` убрана.
- **Пробы:** `ξ_e, ζ_e ~ N(0, MBSIG = 0.5)` -- новые каждые `MBOUT = 20` кругов (проба держится, чтобы тело успело сдвинуться),
  свой жребий `проба`. Новая цель начинает с `α = 0.5, γ = 0` -- **поровну для всех**, без подсказки, кого слушать.
- **Итог пробы:** сумма прироста пользы с ценностью за её 20 кругов, `R = Σ (C + MGAMV·V(после) − V(до))` -- польза за пробу
  плюс сдвиг ценности (куда тело пришло к её концу). Из `R` вычитается то, что ждалось по нервам в начале пробы
  (линейная подгонка по пробам записи) -- остаток `R̃`.
- **Учёба** (раз в 500 кругов, по пробам записи мотора 5000 кругов = 250 проб): для каждой цели по пробам, где её
  предложение было хотя бы в половине кругов: наклон `g = Σ R̃ ξ / Σ ξ²` и его ошибка; `t = g / ошибка`.
  Шаг: `α += MBLR · clip(t, −3, 3)`, `MBLR = 0.05`; так же `γ` по `ζ`. Веса в `[−4, 4]`. Учёба сдвигается, только когда
  проба убедительна; на шуме -- топчется.

Мир, мозг -- Э4/Э5: `WORLD=body KWATER=1 KSAT=1 KTWIN=1 KPAINEV=1 KDEATH=1 KDNERVE=1 KDPEN=30 KPRED=1 BRAIN=9 MVAL=2 MNOPE=1
MLOAN=1000 KEXP=4 MEXP=2 MAVOID=4`.

## 3. Условия -- 24 мира (сиды 1-24, 40000 кругов)

| условие | что | файл |
|---|---|---|
| **Б** | без бегства -- из Э4 | `../e4/e4_B.json` |
| **МС** | смесь, учёба по совпадениям -- из Э5 | `../e5/e5_S.json` |
| **МП** | смесь, учёба по пробам (`MBLEND=2`) | `e5b_P.json` |
| **МП0** | те же пробы, учёбы нет (`MBLEND=2 MBLR=0`: веса навсегда 0.5) -- контроль | `e5b_0.json` |

## 4. Меры -- вторая половина жизни, парно по мирам, двусторонний Уилкоксон, `p < 0.01`

1. **Учёба различает:** в конце жизни у МП вес цели «к» при её средней цене `α + γ · цена` больше 0 -- в доле не меньше
   90% всех целей «к» по 24 мирам (у МС было 67%). Еда полезна всегда -- верный знак известен.
2. **Учёба полезна:** польза тела у МП выше, чем у МП0 (те же пробы, без учёбы).
3. **Лучше прежней учёбы:** польза тела у МП выше, чем у МС.
4. **Компромисс родился:** вес «от» при страхе 3 больше 0 и вес хотя бы одной цели «к» больше 0 -- хотя бы в 20 мирах
   из 24 (как мера 3 Э5).

Дополнительно: МП против Б (польза, укусы, еда); знаки весов «от»; число шагов учёбы.

## 5. Предсказания

- Мера 1 -- **да**: проба «больше слушаться еды» за 20 кругов приближает к еде -- ценность растёт, это видно.
- Мера 2 -- **да, на грани**: 250 проб на подгонку -- немного.
- Мера 3 -- **да**.
- Мера 4 -- **на грани**: польза бегства видна, только когда хищник рядом, -- редкие пробы.
- МП против Б -- польза **не выше** (пробы стоят: руль дрожит).
