# Раунд 1: отделы, сцена, сон, минималист

Три идеи устройства мозга против нынешнего, на экзамене готовности (`../ready/`, `tools/ready.js`): 8 миров, тело ×1 и ×4. Контроли не гонялись: их уже проверяли на нынешнем мозге. Поэтому строки «✗» в файлах там, где сдача зависит от контроля, читать по главной мере.

| участник | ручки |
|---|---|
| нынешний мозг | все механизмы (`../ready/ready_3_final.txt`) |
| **отделы и сцена** | `REG=1 STAGE=8` (`otdely_scena.txt`) |
| **сон** | `SLEEP=1000` (`son.txt`) |
| **минималист** | только части, похожесть, отделы, сцена и сон: без понятий, рабочей памяти, плана и прочего (`minimalist.txt`) |

## Что это

- **Отделы** (`REG=1`, `src/market.js`, `src/memory.js`).
  - Нерв попадает в отдел своего вида: слова, предметы, отвлекающие источники. Деление задано вручную: вид нерва знает мир, а не мозг.
  - В отделе не больше 16 нервов (`RSIZE`).
  - Поиск части, строитель памяти и внимание видят только свой отдел и сцену. Понятия, товары органов памяти и прогнозы частей видны всем — это «проводники» между отделами.
- **Сцена** (`STAGE=8`). 8 самых редких слов-событий видны всем отделам: заметное событие привлекает внимание. Обновляется раз в 500 кругов.
  - Без сцены отделы сразу провалили факт с одного раза (57%): слова и свойство — в разных отделах.
  - Со сценой на 4 места — тоже провал (52%): в неё попали только имена.
- **Сон** (`SLEEP=1000`). Раз в 1000 кругов мир стоит, а мозг по записи:
  - подгоняет все части;
  - ищет (до 3 раз на часть) там, где канал плохо понят;
  - проходит понятиями, схемой и памятью через понятия без предела числа проб.

  Работу сна несёт тело, не части.

## Итог (×1 / ×4)

| опыт (порог) | нынешний | отделы и сцена | сон | минималист |
|---|---|---|---|---|
| факт (75%) | ✓ 98% / 62% | ✓ **100% / 100%** | ✓ 98% / 68% | 49% / 50% |
| факт долгий (75%) | 49% | 53% | 48% | 53% |
| цепочка (50%) | 13% / 4% | 7% / 3% | **21%** / 5% | 0% / 0% |
| ключ, два шага (60%) | 33% / 2% | 8% / 1% | **40%** / 0% | 0% / 0% |
| сложение (0.5) | ✓ 0.61 / 0.50 | ✓ 0.52 / 0.38 | 0.41 / 0.47 | −0.01 / −0.08 |
| перенос (50%) | ✓ 59% / 72% | ✓ 67% / 77% | ✓ 54% / 71% | 0% / 0% |
| память разговора (60%) | ✓ 97% / 92% | ✓ 98% / 100% | ✓ 98% / 91% | 34% / 33% |
| **сдано на ×1** | 4 | 4 | 3 | 0 |
| **сдано на ×4** | 3 | 3 | 2 | 0 |
| работа на ×1 / ×4, тыс. операций за круг | 33 / 300 (×9) | 25 / 155 (**×6**) | 35 / 310 | 20 / 120 |
| текст, бит на знак (2.86 у мозга без механизмов) | 2.85 | 2.85\* | 2.84 | — |

\* В тексте 36 знаков одного вида. С отделами по 16 знак не видел бы других знаков, поэтому для текста отдел — до 40 нервов (`RSIZE=40`). Это особая настройка для одного мира.

От прогона к прогону цепочка и ключ гуляют на ±10 пунктов (у нынешнего мозга цепочка была от 2% до 16%). Поэтому различия меньше этого — не находка.

## Что видно

1. **Отделы режут работу вдвое на ×4 и спасают факт.** На теле ×4 факт с одного раза — 100%, у нынешнего мозга — 62%. Строитель памяти больше не тонет в 70 нервах.

   Но отделы рвут связи между видами нервов. Хуже стали:
   - цель в два шага (8%): «где», «ключ» и мотор — разные виды;
   - вывод в два шага;
   - сложение на ×4.

   Сцена из редких слов это не чинит: «ключ» и «где» не слова. Деление по виду, заданное вручную, разрезает то, что должно быть вместе.
2. **Сон помогает выводу и плану на ×1** (21% и 40% — лучшие числа за все прогоны), но топит сложение (0.41). Причину не разбирал. Догадка: ночью без предела числа проб части пересматривают входы, и равные объяснения снова выбираются наугад. Росту тела сон не помогает: работы даже чуть больше.
3. **Минималист — ноль во всём.** Части, похожесть, отделы и сон без понятий, рабочей памяти и плана не дают ни одной способности. Значит, механизмы — не заплатки, которые можно заменить одной тканью: каждая способность держится на своём органе. Это ответ на мой собственный страх, что механизмы — список заплаток.

## Раунд 2 (предложение)

- **Отделы, которые мозг собирает сам** (идея 2). Вместе — нервы, которые предсказывают друг друга или двигаются одной командой. Тогда «где», «ключ» и мотор окажутся в одном отделе, и цель в два шага не порвётся. Именно это раунд 1 показал как главное слабое место отделов, заданных вручную.
- **Отделы + сон.** Сон дал лучшие вывод и план, отделы — рост тела. Вместе — проверка, складываются ли они.
- **Сон без пересмотра понятий.** Ночью только подгонка и поиск, без прохода через понятия — чтобы сон не ломал сложение.
