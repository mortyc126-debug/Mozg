# Правка «опора-2»: итог -- `CLONGF` ПРИНЯТА, пресет `BRAIN=9`; вместе с «опорой» -- не принята

План и правило приёма -- `ПЛАН.md`, записаны и отправлены до кода.

**Правка** -- ручка `CLONGF`. Сборки, найденные по долгой записи (`PLONG`), проходят те же проверки, что сборки на окне
(`CFAST`):
- не пересказ: выход не совпадает с копией без памяти;
- при чтении выход не постоянен.

До правки долгая запись пропускала пересказы. Например, `при(второе, держать(или(второе, третье), второе))` -- в каждом
круге чтения 1. Такой пересказ перебивал общее понятие и ломал «сложение-3».

**Тождество:** при `CLONGF=0` -- 43 настройки бит в бит (`check.txt`).

## Итог по правилу приёма (база -- `BRAIN=8`, те же миры)

| условие | база | Л: `+CLONGF` | ЛО: `+CLONGF +SUPLOO` |
|---|---|---|---|
| 4. экзамен способностей (этап А) | 7 из 11 | ✓ 7 из 11 | ✓ 7 из 11 |
| 1. «счёт до метки», 17-24 (только ЛО) | 81% | 81% | ✓ 99% |
| 2. задачи нового рода, 17-24 / 9-16 | 8 / 8 из 9 | ✓ 8 / 8 | ✓ 8 / 8 |
| 5. цифры, медиана | 94.3% | ✓ 94.3% | ✓ 94.1% |
| 6. мир-смесь, «понято» | 98% | ✓ 98% | ✓ 98% |
| 3. экзамен готовности, x1 и x4 | 6 из 7 | ✓ 6 из 7 | **✗ 4 из 7** |
| **итог** | | **принят** | **не принят** |

### Что изменилось у принятого варианта Л

| опыт | база | Л |
|---|---|---|
| сложение-3 (экзамен способностей) | 0.57 | **0.61** |
| сложение | 0.52 | 0.52 |

Остальное -- то же число сданного. В экзамене готовности различия -- в сотых.

### Почему не принят ЛО

Экзамен готовности:
- «цепочка» -- 60% -> 49% (порог 50%);
- «сложение» -- 0.52 -> 0.48 (порог 0.5).

Обе ниже порога на несколько сотых. «Сложение» теряется с `SUPLOO` и на экзамене способностей (0.48, как в
`../opora/`). Похоже, это цена смягчённой опоры, а не случайность.

## Предсказания плана

| предсказание | сбылось? |
|---|---|
| тождество | да |
| пересказа в мире 8 нет ни в Л, ни в ЛО | да |
| Л: экзамен способностей не хуже, сложение и сложение-3 выше | не хуже -- да; сложение-3 -- 0.57 -> 0.61, да; сложение -- без изменений, нет |
| ЛО: сложение-3 возвращается выше порога, экзамен 7-8 из 11 | да (0.61, 7 из 11) |
| риск: «долгий факт» упадёт | нет, 93% |

## Решение

- **Пресет `BRAIN=9` = `BRAIN=8 CLONGF=1`** (`src/knobs.js`). `BRAIN=8` и умолчания не меняются.
- Статусы ручек: `CLONGF` -- «несущая»; `SUPLOO` -- «закрыта» (проверена дважды, не принята, оставлена для повторения
  опыта).

## Что осталось открытым

«Счёт до метки» у `BRAIN=9` -- такой же непрочный, как у `BRAIN=8`. На мирах 17-24 -- 81%, в мирах 21 и 23 на уровне
угадывания. «Опора» его чинит (99%), но стоит простому сложению нескольких сотых.

Следующая проба:
- копить доказательство по нескольким окнам **до** правила опоры, не смягчая само правило. Это вариант (б) из
  `../opora/ИТОГ.md`;
- или смягчать опору только для сборок со сбросом (счёт со сбросом по вопросу): именно такие отбрасывались.
