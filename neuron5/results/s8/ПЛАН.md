# Ступень 8: новые действия -- моторная кора. Предрегистрация, до кода

Откуда -- разбор «чего не хватает мозгу» после ступени 7: главный пробел -- мозг не может выучить новое действие, он
только решает, насколько верить каждому из пяти врождённых рефлексов (базальные ганглии, ступень 2а). Что бы он ни понял,
сделать он может лишь то, что умел от рождения. Эта ступень -- в нейроне-5 (по решению автора).

## 1. Мир: преграда (`BARR = 1`)

Стена посреди арены: отрезок поперёк арены (`y = KA/2`, `x` от `0.2·KA` до `0.8·KA`), по краям -- проходы. Сквозь стену
не пройти; касание -- как у стен арены (нервы касания слева и справа). Запах сквозь стену проходит. Когда еда или вода за
стеной, рефлекс тянет тело прямо к ней, рефлекс «от стены» отталкивает, -- и тело топчется у стены. Обойти стену можно,
если при касании поворачивать всё время в одну сторону (идти вдоль стены). Такого рефлекса нет. `BARR = 0` -- прежний
мир бит в бит.

Просьба к родителю (`REQ`) выключена: родитель, приносящий еду к телу, отменил бы задачу. Мозг -- лучший мозг нейрона-5
без просьбы: `BG=1 SPEAK=1 SPX=1 MAP=0 HLAG=10 INV=1 SPT=1`.

## 2. Моторная кора (`MOT = 1`, `organs/motor.js`; вне рынка)

К команде двигателя добавляется **своё движение**: `Σ_j w_j · x_j`, `x_j` -- ощущения (все нервы, каждый в своих единицах:
минус бегущее среднее, делить на бегущий разброс). `w` начинает с 0 (у новорождённого своих движений нет). Учёба -- как у
ганглиев (принцип 3): пробы `w_j + ζ_j` держатся `BOUT` кругов, итог пробы -- сумма ошибок ожидания ценности; раз в `BFIT`
кругов `w_j` сдвигается на `MLR · clip(t)` по убедительности наклона итога по пробе (проба взвешена тем, как вход звучал).
Какие ощущения и с каким знаком поворачивают тело -- мозг учит сам. `MOT = 2` -- контроль: пробы есть, учёбы нет.

## 3. До основного счёта -- диагностика (дым: сиды 101–103)

Движение задано рукой: к команде добавлено `g · (касание слева + касание справа)` (при касании -- поворот всегда в одну
сторону), `g = 0, 1, 2, −1, −2`, в мире с преградой. Если ни при каком `g` еды не больше, чем при `g = 0`, -- мир не годится,
и это записывается до счёта.

## 4. Условия -- 24 мира (сиды 1-24, 40000 кругов)

| условие | что | файл |
|---|---|---|
| Б | преграда, без моторной коры | `s8_B.jsonl` |
| **М** | преграда, моторная кора (`MOT=1`) | `s8_M.jsonl` |
| М0 | преграда, пробы без учёбы (`MOT=2`) | `s8_M0.jsonl` |
| О | без преграды, без моторной коры | `s8_O.jsonl` |
| ОМ | без преграды, моторная кора | `s8_OM.jsonl` |

## 5. Меры -- вторая половина жизни; парно по мирам, двусторонний Уилкоксон, `p < 0.01`

1. **Выучил новое действие:** еда + вода у М больше, чем у Б.
2. **Учёба, а не шум проб:** еда + вода у М больше, чем у М0.
3. **Не мешает там, где не нужно:** польза ОМ не ниже, чем у О.
4. **Понимание и речь не теряются:** AUC «еда», «вода», доля названной еды у М -- без значимого падения против Б.

Дополнительно: веса касаний (одного ли знака -- «иди вдоль стены»), доля кругов у преграды, польза М против Б.

## 6. Предсказания

- Диагностика -- **выигрыш есть** при `|g| = 1–2`.
- Мера 1 -- **на грани**: около 30 весов, 20 шагов учёбы за жизнь; ганглии учили 4 веса.
- Мера 2 -- **на грани**. Меры 3, 4 -- **да**.

## 7. Запись до основного счёта

Данные -- `diag/` (сиды 101–103). Еда + вода на 1000 кругов, среднее трёх миров:

| | еда + вода | польза |
|---|---|---|
| без преграды | 20.02 | 2.568 |
| преграда | 11.88 | 1.448 |
| преграда, рукой g = 1 / 2 / −1 / −2 | 13.73 / **14.55** / 14.28 / 14.07 | 1.67 / 1.73 / 1.78 / 1.71 |
| преграда, моторная кора как в плане (проба σ = 0.3 на каждый вход) | 7.98 | 0.646 |
| то же, пробы без учёбы | 8.22 | 0.756 |
| поправка 1: проба σ/√N на вход | 7.67 | 0.670 |
| то же, пробы без учёбы | 12.28 | 1.394 |
| поправка 2: шаг веса только при \|t\| ≥ 2.5 | 8.17 | 0.657 |
| без преграды, поправки 1–2 | 16.55 | 2.304 |

1. **Мир годится:** преграда отнимает 40% еды, а движение «при касании поворачивай в одну сторону», заданное рукой,
   возвращает треть потери (+22%). Оба знака помогают -- задача симметрична.
2. **Поправка 1** (до счёта): проба на вход -- σ/√N (вся проба по N ≈ 28 входам -- около σ, как у ганглиев). Иначе одни
   пробы шатают тело (суммарный шум ≈ 1.6) и стоят трети еды.
3. **Поправка 2** (до счёта): шаг веса -- только при убедительной пробе (`MTMIN = 2.5`), иначе 28 весов блуждают по шуму.
4. **Механизм не работает уже в дыму:** учёба хуже, чем без неё, и с преградой, и без. Веса уходят на посторонние входы
   (слова, рот, запахи); малые веса на редких нервах (в единицах своего разброса они велики, когда звучат) резко дёргают
   тело; хороших направлений среди 28 входов мало, а шум итога пробы велик. Плюс задача симметрична: в точке w = 0 выигрыш
   растёт в обе стороны, и наклон итога по пробе там около нуля -- линейная проба его не видит.
5. Предсказания мер 1–2 теперь выглядят неверными. Механизм дальше не подгоняю; основной счёт -- как записано, с
   поправками 1–2 (`MSIG=0.3 MTMIN=2.5`).
