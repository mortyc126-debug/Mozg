# Э2: мозжечок -- прямая модель с копией команды. Предрегистрация, до кода

Откуда -- `results/e1/ИТОГ.md` и `БИОЛОГИЯ.md`. В Э1 руль по прогнозам частей был вдвое хуже руля по нервам: части
предсказывают нерв по прошлому и не знают, куда тело повернёт, -- их прогноз запаздывает. В мозге эту работу делает
мозжечок: он получает **копию своей команды** и предсказывает, как изменятся чувства от собственного движения. И в мозге
такой прогноз -- **советник** рулю, а не его единственные глаза.

## 1. Мозжечок (`CER`, в мире тела, при мото­ре ожиданий `MEXP = 2`)

- **Прямая модель.** Для каждого нерва `k` (кроме своих нервов мотора) -- линейная подгонка по записи мотора (5000 кругов,
  раз в 500 кругов): `x_k(t+1) − x_k(t) ~ b0 + b·x(t) + u(t)·(c0 + c·x(t))`, `u(t)` -- команда этого круга (копия
  команды). У всех нервов одна матрица признаков -- считается один раз. Работа -- на счёт мотора.
- **Прогноз.** Каждый круг после команды мозжечок предсказывает нервы следующего круга: `x̃(t+1)`.
- **Совет рулю.** Руль цели (как в М3в) видит **и нервы `x`, и прогноз мозжечка `x̃`** (признаков вдвое больше); подгонка руля
  сама решает, сколько веса дать прогнозу. Сигнатура (цель руля) -- по нервам, как в М3в. Прежний мотор -- по нервам.
- `CER = 1` -- с копией команды; `CER = 2` -- **контроль без копии**: та же модель без членов с `u`.

`CER = 0` -- как М3в. Остальное -- М3в в копии (`KEXP=3 MEXP=2`), без экономики Э1.

## 2. Условия -- мир М3 (еда и вода, сытые блоки, смерть), 24 мира (сиды 1-24, 40000 кругов)

`WORLD=body KWATER=1 KSAT=1 KTWIN=1 KPAINEV=1 KDEATH=1 KDNERVE=1 KDPEN=30 BRAIN=9 MVAL=2 MNOPE=1 MLOAN=1000 KEXP=3 MEXP=2`.

| условие | что | файл |
|---|---|---|
| **Б** | М3в (без мозжечка) -- из Э1 | `../e1/e1_B.json` |
| **МЗ** | мозжечок с копией команды (`CER=1`) | `e2_C.json` |
| **МЗ0** | мозжечок без копии (`CER=2`) | `e2_N.json` |

## 3. Меры -- вторая половина жизни, парно по мирам, двусторонний Уилкоксон, `p < 0.01`

0. **Механизм:** ошибка прогноза мозжечка на нервах запахов (средний квадрат), делённая на ошибку «будет как сейчас»
   (`x(t+1) = x(t)`). У МЗ меньше, чем у МЗ0, -- копия команды помогает предсказывать. Нет -- меры 1-2 читаются с
   оговоркой.
1. **Совет помогает рулю:** еда + вода у МЗ больше, чем у Б.
2. **Дело в копии команды:** еда + вода у МЗ больше, чем у МЗ0.

Дополнительно печатается: смерти, выбор по нужде, обесценивание; МЗ0 против Б.

## 4. Предсказания

- Мера 0 -- **да**: поворот сразу меняет запахи слева и справа (датчики поворачиваются вместе с телом), и без копии
  команды этот сдвиг не предсказать.
- Мера 1 -- **слабо**: прогноз, знающий поворот, -- это «куда будет пахнуть после поворота»; рулю он даёт немного сверх
  нервов. Ожидаю +1-2 еды, на грани значимости.
- Мера 2 -- **да**, если 1 -- да.
