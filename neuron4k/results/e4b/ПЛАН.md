# Э4б: страх включает осторожность раньше погони. Предрегистрация, до кода

Откуда -- `../e4/ИТОГ.md`. Миндалина ждёт укус (24 из 24) и точно чувствует близость хищника (страх / средний: дальше 15 --
0.3-0.4, 9-15 -- ~1, 6-9 -- ~2, ближе -- 3-6). Но бегство по порогу «страх > 2 средних» включалось на границе погони, когда
убежать уже нельзя, -- укусов не меньше. Без миндалины тело держалось далеко всегда -- укусов меньше, но голод.

## 1. Правка -- два способа включать цель «от» раньше

- `MAVOID = 3` -- **порог ниже:** цель «от» допускается, когда страх выше **одного** своего среднего (хищник около 9-15,
  погони ещё нет).
- `MAVOID = 4` -- **без порога, сила по страху:** цель «от» соревнуется всегда, но её заметность умножена на страх / средний
  страх (далеко -- втрое слабее, рядом -- в 3-6 раз сильнее). Цели «к» -- как прежде.

Всё остальное -- Э4. `MAVOID = 0, 1, 2` не меняются.

## 2. Условия -- мир и мозг Э4, 24 мира

| условие | что | файл |
|---|---|---|
| **Б** | только цели «к» -- из Э4 | `../e4/e4_B.json` |
| **МУ** | бегство без миндалины -- из Э4 | `../e4/e4_U.json` |
| **М1** | порог «выше одного среднего» (`MAVOID=3`) | `e4b_1.json` |
| **МП** | сила по страху (`MAVOID=4`) | `e4b_P.json` |

## 3. Меры -- вторая половина жизни, парно по мирам, двусторонний Уилкоксон, `p < 0.01`

Для каждого из М1, МП:
1. **Реже кусают:** укусов меньше, чем у Б.
2. **Ест:** еда + вода не меньше, чем у Б (нет значимого падения).

**Страх меняет поведение без голода** -- если хотя бы у одного из М1, МП выполнены 1 и 2.

Дополнительно: против МУ (еда), смерти, доля кругов с целью «от».

## 4. Предсказания

- М1: укусов меньше -- **да**; еда -- **на грани** (цель «от» включена чаще, ~40% кругов).
- МП: укусов меньше -- **да**; еда -- **да, без падения**: вдали страх слаб, и цели «к» побеждают.
- Итог -- **да**, через МП.
