# Предрегистрация: усиление петли тишины по всей сети

Написано до кода и до прогонов. Замеры, проверки самого замера, правило чтения и
что из какого исхода следует объявлены заранее. `neuron2.js` -- копия v31 без
изменений. Механизма в шаге нет.

## 1. Откуда вопрос

Шаг 42: подстановка ожидания на место молчащего датчика (`HOLD`) несёт знание
сквозь короткую тишину (`H(10)` 0.64 против 0.18), но в трети миров разгоняет
сеть до взрыва. Разбор после чтения: отдельная часть устойчива
(`wSelf + ws ≈ 0.96`), сеть целиком -- нет. Правило 20: устойчивость меряется по
всей системе. Здесь она меряется.

## 2. Что меряется

В тишине веса, нормировки и хозяйство заморожены, поэтому один круг тишины --
**одно и то же линейное отображение** состояния `x = (прогнозы всех частей,
сигналы всех частей)`. Нелинейно только ограничение сигнала `±4`; его замер
отбрасывает, а ограничение может лишь гасить. Строки матрицы `A` по коду `pauseRound`:

- прогноз `i`: `HOLD·wSelf_i·pred_i + ws_i·pred_i + Σ w_l·V_l` по проверенным
  связям (пробные в прогноз не входят);
- сигнал `i`: `(HOLD·uSelf_i·pred_i + Σ u_l·V_l) / √(zv_i + 10⁻⁹)` по всем связям;
- `V_l` -- сигнал продавца (`k = 2`), его прогноз (`k = 1`) или его датчик (`k = 0`),
  который в тишине равен `HOLD·pred_j`.

Перед каждой тишиной (веса ровно те, что будут в ней) строятся три матрицы:

- **`A_H`** -- с подстановкой (как при `HOLD = 1`);
- **`A_0`** -- без неё (как при `HOLD = 0`);
- **`A_л`** -- **личная подстановка**: ожидание входит только в прогноз и сигнал
  самой части, покупатели её датчика видят молчание. Этого варианта нет в
  движке; его радиус считается как прогноз для следующего шага.

Для каждой:

- **спектральный радиус** `r` -- асимптотическое усиление за круг
  (степенной метод: средний логарифм роста за круги 201-400 из 400);
- **наибольшее сингулярное число** `σ` -- наибольший разгон за один круг.

Для `A_H` ещё:

- `max |wSelf_i + ws_i|` -- наибольшее усиление отдельной части на себя;
- доля ведущего собственного вектора по каналам (канал `S`, каналы 0-2 и 8,
  каналы 3-7, канал 9).

По каждой тишине записывается **разгон** -- наибольшее за тишину отношение RMS
прогнозов всех частей к RMS в последнем круге жизни, как в шаге 42.

## 3. Прогоны

Мир и схема циклов шага 42 (`DEEP=2 EAT=0 SLOW=1 PAYL=1 SELFREC=1`, вес на себя
учится; 60000 кругов, 20 циклов с тишиной 10, 20 циклов с тишиной 30). Те же сиды
1301-1312 при `HOLD = 0` и `HOLD = 1`: вопрос в том, объясняет ли радиус
**именно те** взрывы. Мир после гибели не считается.

## 4. Проверки самого замера (не выполнены -- замер сломан, чтения нет)

- **П1. Матрица -- это тишина.** Отдельным прогоном (сиды 1-3, после 60000
  кругов, `HOLD = 0` и `1`): `A·x` против одного настоящего `pauseRound` --
  расхождение прогнозов не больше `10⁻⁹`, и сигналов тоже, где ограничение не
  сработало.
- **П2. Радиус считается верно.** На пробной матрице с известным радиусом
  (блок поворота с модулем 1.05 и диагональ 0.9, размер 50) ошибка не больше 0.01.
- **П3. Замер не трогает мир.** `H(10)` и `H(30)` по каждому сиду совпадают с
  `v31/out/run.tsv` до последнего знака.

## 5. Правило чтения

- **А. Сеть с подстановкой неустойчива.** В прогоне `HOLD = 1` у каждого сида
  доля тишин с `r_H > 1`; медиана по сидам не ниже **0.25**.
- **Б. Взрыв объясняет усиление.** По всем тишинам прогона `HOLD = 1` (сиды
  вместе) предсказание «взорвётся» -- по двум правилам: **асимптотическому**
  `r_H^T > 2` и **однокруговому** `σ_H > 2`. Взрыв -- разгон больше 2, как страж
  шага 42. Правило «объясняет», если точность не ниже 0.9 **и** из взорвавшихся
  тишин предсказано не меньше 0.8. Оба правила записываются.
- **В. Часть устойчива, сеть нет.** Среди тишин с `r_H > 1` доля тех, где у всех
  частей `|wSelf + ws| < 1`, не ниже 0.5.
- **Г. Без подстановки устойчиво.** Доля тишин с `r_0 > 1` в обоих прогонах --
  записывается.
- **Д. Личная подстановка устойчива.** Доля тишин с `r_л > 1` в обоих прогонах не
  больше **0.02**.

## 6. Что из какого исхода следует

- **А и Б** -- взрыв шага 42 -- это усиление петли тишины через всю сеть. Механизм
  удержания обязан держать радиус сети ниже 1.
- **Д выполнено** -- следующий шаг: личная подстановка (покупатели видят
  молчание), с предрегистрацией и тем же мерилом `H`. Её устойчивость уже
  предсказана замером.
- **Д не выполнено** -- следующий шаг: механизм, держащий усиление сети ниже
  единицы (например, общая нормировка активности в тишине), с предрегистрацией.
- **Б не выполнено ни одним правилом** -- взрыв не линейный: смотреть на
  ограничение сигнала и первый круг после тишины.

## 7. Предсказания

1. П1-П3 выполнены.
2. А выполнено: `r_H > 1` в 30-50% тишин.
3. Б: асимптотическое правило объясняет взрывы в длинных тишинах, однокруговое --
   в коротких. Вместе -- да, по отдельности каждое, вероятно, не дотянет до 0.9.
4. В выполнено.
5. `r_0 < 1` во всех тишинах.
6. Д выполнено: `r_л < 1` почти везде, потому что диагональ `wSelf + ws < 1`, а
   остальное -- устойчивая матрица без подстановки.
7. Ведущий вектор `A_H` лежит не в канале `S`, а в быстрых каналах и сигналах.

## Поправка до основного замера (П2 не выполнена степенным методом)
