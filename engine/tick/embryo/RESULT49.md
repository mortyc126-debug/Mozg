# Результат шага 49: в тишине отмирают связи, державшиеся только сигналом

Предрегистрация -- `PRE49_LINKS.md`, закоммичена до кода. Механизма нет. Зародыш
после шага 48, сиды 2201-2212, 60000 кругов жизни, затем 100 кругов свободной
активности. Замер -- `links.js`, строки -- `out/links49.tsv`.

## Все проверенные связи: было 3092, исчезло 1593 (51.5%)

| причина | связей | доля исчезнувших |
|---|---|---|
| 1. погиб владелец | 85 | 5.3% |
| 2. погиб продавец | 42 | 2.6% |
| 3. держалась прогнозом | 18 | 1.1% |
| 4. только сигналом, упал спрос | 8 | 0.5% |
| **5. только сигналом, упала сигнальная доля** | **1440** | **90.4%** |

**Главная причина -- 5** (порог 0.5; по сидам медиана тоже 90.4%). По виду товара:
датчик 638, прогноз 396, сигнал 406 -- все виды.

Главное число: на начало тишины **только сигналом держалась половина проверенных
связей (1588 из 3092)**, и из них за 100 кругов отмерло 91%. Связей, державшихся
прогнозом, отмерло 18 из 1504 (1.2%). Правило доли шага 48 путь прогноза держит.

## Верные связи смесей: было 1151, исчезло 146 (12.7%)

Главная причина -- тоже 5 (63.7%); ещё 35.6% -- гибель владельца или продавца
(сбои без рождений). Верные связи теряются вчетверо реже прочих, потому что
держатся в основном прогнозом.

## Исход по §5

**5 главная** -- путь сигнала надо судить так же, как путь прогноза: по доле, с
согласованными окнами. Причина подтверждена расчётом до замера. `r2` (окно ~20
кругов) гаснет быстрее `zv` (окно ~100 кругов), и отношение падает само по себе.
Механизм -- отдельной предрегистрацией, приёмка по табло.

## Предсказания §6

1. Исчезает около половины -- **да** (51.5%).
2. Главная -- 5, около 70% -- **да, больше**: 90.4%.
3. Причина 3 меньше 15% -- **да** (1.1%); причины 1-2 около 8% -- **да** (7.9%).
4. Верные связи смесей теряются реже -- **да** (12.7% против 51.5%).
