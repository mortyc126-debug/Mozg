# Табло зародыша

Одна конфигурация (`embryo.env`), один движок (`neuron2.js`), одна батарея
(`battery.js`, правила -- `BATTERY.md`). Изменение движка принимается, только если
табло не падает. Каждый прогон батареи дописывается сюда сверху.

## Прогон 1 -- шаг 47, сиды 2001-2012, вымерших миров нет

| строка | статус | мера |
|---|---|---|
| 0 живёт между касаниями | **ЕСТЬ** | `H(10)` 0.747, `H(30)` 0.665 (порог 0.5) |
| 1 принимает мир | дана | конструкцией мира |
| 2 держит след опыта | **ЕСТЬ** | вес на верных связях 99.3% (порог 95%, нуль 37.9%) |
| 3 след во времени, путь В | нет | канал 9 держит прошлое в 90% замеров в 5 сидах из 12 (порог 6) |
| 3 след во времени, прямо | нет | после 100 кругов свободной активности `R` смесей 0.153, канала S 1.30 (порог 0.9) |
| 4 проводит на расстояние | **ЕСТЬ** | `bits9 > 0.6` в 8 сидах из 12 (порог 6), медиана 1.41 |
| 5 собственное прошлое | нет | меры нет |
| 6 действует и различает удачу | **наполовину** | верных действий 41.5% против жребия 19.9%, p = 3.7·10⁻⁷; различение удачи держится на отборе |
| 7 сводит два входа | **ЕСТЬ** | биты каналов 3, 4, 5, 7 -- 2.86 (порог 1.5; один вход даёт не больше 0.68) |
| 8 различает порядок | нет | меры нет |

**Итог: 4 строки есть (0, 2, 4, 7), одна дана (1), одна наполовину (6), три нет
(3, 5, 8).**

Изъян меры, записанный после чтения. Условие смены состава в строке 3 путь В
оказалось пустым: ни одна часть, живая на 60000-м круге, не дожила до 100000-го
ни в одном сиде (одни сбои за 40000 кругов оставляют ~10⁻⁶). Путь В решило одно
удержание канала 9 -- 5 сидов из 12 при пороге 6. Статус по правилу -- нет.
Мера смены состава на следующий прогон батареи переписывается до прогона.

`H` по отдельным сидам шумит (от −0.9 до 19.7): 20 тишин на сид, малый
знаменатель. Решают медианы, как в шаге 45.
