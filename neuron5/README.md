# Нейрон-5

Новое ядро с чистого листа: одна шина для всех органов, плата по вкладу, гиппокамп в ядре, тело и язык в одном мире.
План и принципы -- `PLAN.md`. Нейрон-4 (`../neuron4`, `../neuron4k`) -- мерка, против которой сдаются экзамены.

**Чистка ядра** (по решению автора, после ступени 6в): удалены ветки, не прошедшие экзамен, -- выбор по страху и миндалина
(`BCTX`, 2б), цена слова по телу (`SPB`, 5 и 5б-Б), формы «ещё не было» и выученный риск (`INVF`), принятие по ΔP (`INVC`),
предвестники конца сигнала (`HOFF`), таламус (`THAL`, 6в). Их опыты воспроизводятся из коммита `61f30e4`. Сданные линии
(2а, 3, 4, 5б-А, 5б-Б без `SPB`, 6, 6б) после чистки воспроизводятся бит в бит (проверено по сиду 1). Ступень 1 -- из коммита
`e8db318`: ядро изменилось на ступени 2а (рефлексы стали товарами шины), ещё до чистки.

Запуск экзамена ступени 1 для одного мира: `node tools/exam1.js <сид> [РУЧКА=значение ...]`; все ручки -- `src/config.js`.
