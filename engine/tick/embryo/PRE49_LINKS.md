# Предрегистрация шага 49: почему в тишине отмирают связи

Написано до кода замера и до прогонов. Механизма в шаге нет: только замер
причин. Движок и конфигурация -- зародыш после шага 48 (`embryo.env`, `neuron2.js`).

## 1. Откуда вопрос

Шаг 48: в тишине деньги спят и связь судится по доле, но из проверенных связей
за 100 кругов тишины отмирает половина. Смеси теряют около 12% знания.

## 2. Как связь может исчезнуть в тишине

Связь проверенная (возраст не меньше `TRIAL`) остаётся, пока выполнено хотя бы
одно из двух:

- **путь прогноза:** `|w| · √(r2 · Vc / r2s) ≥ 0.15` (с шага 48 -- по доле);
- **путь сигнала:** спрос на сигнал части `zb > 0.3` **и** `|u| · √(r2 / zv) ≥ 0.15`.

Иначе она отмирает. Ещё связь исчезает со смертью владельца или продавца (сбои в
тишине идут).

**Предположение до замера.** Путь сигнала шаг 48 не трогал. В нём `r2` --
мощность входа, окно около 20 кругов (0.05), а `zv` -- мощность сигнала части,
окно около 100 кругов (0.01). В тишине `r2` гаснет быстрее `zv`, отношение падает
как `(0.95/0.99)^k`: за 100 кругов в 60 раз. Связи, которые держались только
сигналом, отмирают. Путь прогноза по доле, по расчёту, теряет лишь пограничные
связи.

## 3. Замер

Зародыш, новые сиды 2201-2212. 60000 кругов жизни, затем 100 кругов свободной
активности. На начало тишины у каждой проверенной связи записываются: вклад по
пути прогноза, вклад по пути сигнала, спрос `zb` владельца, вид товара, каналы
владельца и продавца. Для каждой исчезнувшей связи причина -- ровно одна, по
порядку:

1. **погиб владелец**;
2. **погиб продавец** (связь снята или пересажена родичу);
3. **отмерла, держалась прогнозом** -- на начало тишины вклад по пути прогноза не
   ниже порога;
4. **отмерла, держалась только сигналом, упал спрос** -- на начало тишины держалась
   только путём сигнала, а на момент отмирания `zb ≤ 0.3`;
5. **отмерла, держалась только сигналом, упала сигнальная доля** -- то же, но
   `zb > 0.3`, а `|u|·√(r2/zv)` ниже порога.

Отдельно -- **верные связи смесей**: владелец в каналах 3-7, продавец -- его
родитель (или дед для товара «прогноз»), как в мере строки 2.

## 4. Правило чтения

- **Главная причина** -- категория с долей не меньше **0.5** среди исчезнувших
  проверенных связей (все сиды вместе; медиана по сидам -- для отчёта). Нет такой
  -- причина «смешанная», записываются доли.
- То же -- отдельно для верных связей смесей.

## 5. Что из какого исхода следует

- **5 главная** -- путь сигнала надо судить так же, как путь прогноза: по доле, с
  согласованными окнами. Механизм -- отдельной предрегистрацией, приёмка по табло.
- **3 главная** -- `r2s` -- не та мерка для доли. Сравнивать с мощностью входов
  части, а не с её ожиданием.
- **4 главная** -- в тишине падает спрос на сигнал; разбирать, почему.
- **1-2 главная** -- связи уходят со сбоями частей; это объявленная цена сна
  (сбои идут, рождений нет), и правило связей тут ни при чём.

## 6. Предсказания

1. Исчезает около половины проверенных связей (как в шаге 48).
2. **Главная причина -- 5** (сигнальная доля), около 70% исчезнувших.
3. Причина 3 -- меньше 15%, причины 1-2 -- около 8% (4% частей за 100 кругов, связь
   теряется с любым из двух концов).
4. Среди верных связей смесей исчезает меньше, чем в среднем: они держатся
   прогнозом.
