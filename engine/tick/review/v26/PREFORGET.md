# Предрегистрация: чего стоит забывание за паузу

Написано до кода и до прогонов. Шаг 36 измерил, что сеть молчит в паузе. По
четырнадцатому правилу механизм собственной активности вводится только под
функцию. Этот шаг меряет функцию: **что теряется, когда активность гаснет.**
Механизма в шаге нет; `neuron2.js` -- тот же, что в шаге 36.

## 1. Что такое цена забывания здесь

В паузе мир заморожен: после неё он продолжается с того места, где
остановился. Значит «удержать всё через паузу» в точности совпадает с «паузы не
было». Цена забывания -- разница между прогнозами после паузы и прогнозами без
неё. Она же -- **потолок** того, что может вернуть любой механизм
собственной активности.

## 2. Замер

Мир шага 36 (`DEEP = 2`, `EAT = 0`), новые сиды 701-712. 60 000 кругов жизни,
затем 20 циклов: 200 кругов жизни -- пауза 50 кругов -- 20 кругов жизни.

Для каждой части в каждом круге жизни -- квадрат ошибки прогноза
`e² = (датчик − вчерашний прогноз)²`. На цикл:

- **отсчёт** -- средний `e²` части за последние 50 кругов перед паузой;
- **лишняя ошибка** -- сумма по 20 кругам после паузы `(e² − отсчёт)`;
- **в кругах полного незнания:** сумма лишней ошибки по частям, делённая на сумму
  `(V − отсчёт)` по частям, где `V = 1 + SN²` -- ошибка части, не знающей
  ничего. Одна такая единица -- один круг, прожитый так, будто всё забыто.

Отдельно по группам: источники (каналы 0, 1, 2, 8), смеси (3-7), канал 9
(глубокое прошлое).

**Пустой отсчёт:** те же циклы **без паузы**, та же мера. Обязан дать около нуля
(модуль медианы меньше 0.3 круга). Иначе мера сломана.

**Страж пути А:** вес на верных связях после 20 циклов с паузами -- не ниже 95%
(в шагах 22-35 держался 95-100% при нуле 36-41%).

## 3. Правило чтения

По медиане по 12 сидам, цена на одну паузу, все части:

- **существенна** -- не меньше **5** кругов полного незнания: пауза стирает
  больше, чем длина цепочек. У активности между касаниями есть работа уже в
  этом мире; следующий шаг -- механизм;
- **мала** -- меньше **2** кругов: забывание стоит примерно столько, сколько
  стоит заново наполнить цепочки. Механизм вернул бы не больше этого.
  Следующий шаг -- дать миру медленную составляющую, которую есть смысл держать;
- между -- записывается как есть.

## 4. Предсказания

1. Цена **мала**: около одного круга полного незнания в среднем.
2. У канала 9 цена выше, около `DEEP = 2` кругов: ему нужно глубокое прошлое, а
   цепочка, которая его несёт, после паузы пуста и наполняется два круга.
3. Пустой отсчёт около нуля.
4. Страж держится: пауза без учёбы и без хозяйства выученного не портит.
